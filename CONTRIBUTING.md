# Contributing
This project accepts feature requests and contributions from the open source community. 
Fork the repository and create a branch for your change.

## Development environment requirements
see [Requirements for developing the application](README.md#Requirements-for-developing-the-application)

### Building the application
see [Building the application](README.md#Building-the-application)

## Pull requests
When your branch is ready, open a pull request. 
All changes should include appropriate test coverage. 
Maintainers will review the change and merge it when it is ready.
